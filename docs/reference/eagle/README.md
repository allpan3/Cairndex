# Eagle UI reference

This directory holds reference screenshots of the Eagle (eagle.cool) app used
as interaction references for Cairndex's UI work (`AGENTS.md` §8).

**The image files in this folder are git-ignored and must not be committed.**
Only this `README.md` is tracked, so the folder exists in the repo while the
screenshots stay local to each developer's checkout (see the root
`.gitignore`). Never put private source media (videos, personal photos) here
either.

The product owner is expected to add the following named screenshots here
(see `AGENTS.md` §8 and the product brief):

- `main-library-justified-layout.png` — Main library view (justified layout)
- `list-layout.png` — List layout view
- `metadata-panel.png` — Metadata panel
- `folder-tree.png` — Folder tree
- `tag-select-view.png` — Tag select view
- `top-bar-in-folder.png` — Top bar inside a folder
- `smart-folder-creation.png` — Smart Folder creation

Reference these images by relative path from `docs/architecture.md` and any
UI-milestone PR summary once they are added. Treat any image dropped in this
folder as the product owner's own screenshots, not redistributable assets —
do not move them elsewhere or assume a license to share them outside this
repository.
